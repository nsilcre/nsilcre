### Requisitos previos
- **PHP 8.2+**
- **Composer** (gestor de dependencias PHP)
- **MySQL 8.0+**
- **Node.js** (para compilar CSS/JS)

### Instalación paso a paso

```bash
# 1. Clonar el repositorio
git clone https://github.com/tu-usuario/crud-breeze.git
cd crud-breeze

# 2. Instalar dependencias PHP
composer install

# 3. Instalar Laravel Breeze (si no viene incluido)
composer require laravel/breeze
php artisan breeze:install blade

# 4. Instalar dependencias Node
npm install && npm run build

# 5. Configurar el archivo .env
cp .env.example .env
php artisan key:generate

# 6. Configurar la base de datos en .env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=concesionario
DB_USERNAME=root
DB_PASSWORD=

# 7. Ejecutar migraciones
php artisan migrate

# 8. (Opcional) Insertar datos de prueba
php artisan db:seed

# 9. ¡Listo! Inicia el servidor
php artisan serve
```

Accede a **http://localhost:8000** en tu navegador

## � Cómo usar la aplicación

1. **Registrarse** → Ve a `/register` y crea tu cuenta
2. **Login** → Accede con tus credenciales
3. **Dashboard** → Explora el panel de control
4. **Gestionar vehículos** → Navega a Vehículos:
   - 📋 **Ver listado** - Tabla paginada de todos los vehículos
   - ➕ **Crear nuevo** - Botón para añadir un vehículo
   - ✏️ **Editar** - Modifica datos existentes
   - 🗑️ **Eliminar** - Borra registros (con confirmación)

## � Estructura del Proyecto

```
app/
├── Models/
│   ├── User.php              # Modelo de usuario (Breeze)
│   └── Vehiculo.php          # Modelo de vehículos
├── Http/
│   └── Controllers/
│       └── VehiculoController.php  # Lógica del CRUD
└── Providers/
    └── AppServiceProvider.php      # Configuración

resources/views/
├── layouts/
│   └── app.blade.php         # Template principal
├── auth/                      # Vistas de autenticación
│   ├── register.blade.php
│   ├── login.blade.php
│   └── forgot-password.blade.php
└── vehiculos/                # Vistas del CRUD
    ├── index.blade.php       # Tabla de vehículos
    ├── create.blade.php      # Formulario creación
    ├── edit.blade.php        # Formulario edición
    └── show.blade.php        # Detalle del vehículo

database/
├── migrations/
│   ├── *_create_users_table.php       # Tabla usuarios
│   └── *_create_vehiculos_table.php   # Tabla vehículos
└── seeders/
    └── VehiculoSeeder.php    # Datos de prueba (opcional)

routes/
└── web.php                   # Definición de rutas
```

## � Preguntas Frecuentes

**¿Necesito XAMPP?**
> No es obligatorio, pero facilita tener MySQL y PHP listos. También puedes usar WAMP, LAMP o WSL.

**¿La contraseña de admin es segura?**
> En desarrollo es `123456` por simplicidad. En producción **SIEMPRE** cambiarla y usar credenciales fuertes.

**¿Cómo limpio la base de datos?**
> Ejecuta `php artisan migrate:refresh --seed` (borra todo y vuelve a llenar con datos de prueba)
